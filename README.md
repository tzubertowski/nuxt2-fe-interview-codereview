# Frontend Interview - Code Review Exercise

Nuxt 2 application with intentional code quality issues.

## Setup

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Task

Review codebase. Identify issues, suggest improvements.

## What's included

- One page (pages/index.vue)
- One component (components/BadComponent.vue)
- Basic Nuxt 2 configuration

Time: 30-45 minutes
